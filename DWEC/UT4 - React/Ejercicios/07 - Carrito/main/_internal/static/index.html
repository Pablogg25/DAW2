🏦 Banco de Pruebas API

Aprende a consumir APIs REST con JavaScript

📚 ¿Qué es este proyecto?

Un banco de pruebas didáctico construido con FastAPI para aprender a:

🔐 Autenticación JWT

Login, tokens de sesión, protección de endpoints

🛒 APIs REST

GET, POST, PUT, DELETE con validaciones

📊 Bases de Datos

Relaciones 1:N, respuestas agrupadas

🧪 JavaScript Fetch

Consumo desde navegador con ejemplos interactivos

🚀 Acceso Rápido

📖 Swagger (API Docs) 📝 ReDoc 🧪 Página de Pruebas 💚 Health Check

📡 Rutas Principales

Autenticación:

  • POST /auth/login - Obtener token JWT
  • POST /auth/logout - Cerrar sesión

Usuarios:

  • POST /usuarios - Registrarse
  • GET /usuarios/me - Mi perfil (requiere JWT)
  • PUT /usuarios/me - Editar mi perfil (requiere JWT)

Productos (público):

  • GET /productos - Listar todos
  • GET /productos/{id} - Detalle

Pedidos (cliente autenticado):

  • GET /pedidos - Mis pedidos
  • GET /pedidos/{id} - Detalle con líneas
  • POST /pedidos - Crear pedido
  • PUT /pedidos/{id}/lineas/{id} - Editar línea
  • DELETE /pedidos/{id}/lineas/{id} - Eliminar línea

Admin:

  • GET /admin/usuarios - Listar usuarios
  • PUT /admin/usuarios/{id}/estado - Cambiar estado usuario
  • GET /admin/productos - Listar todos (incluyendo inactivos)
  • POST /admin/productos - Crear producto
  • PUT /admin/productos/{id} - Editar producto
  • GET /admin/pedidos - Listar todos los pedidos
  • PUT /admin/pedidos/{id}/estado - Cambiar estado pedido

📖 Notas Educativas

  • ✅ Los datos se almacenan en memoria (se reinician al arrancar)
  • ✅ JWT tiene expiración de 1 hora
  • ✅ Validaciones con errores 422 Unprocessable Entity
  • ✅ Autenticación con status 401 Unauthorized
  • ✅ Autorización con status 403 Forbidden
  • ✅ Relaciones 1:N con respuestas agrupadas (Pedido + Líneas)
  • ✅ Admin puede ver y editar todo
  • ✅ Cliente solo ve sus datos
